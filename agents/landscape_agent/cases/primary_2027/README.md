# Prospective primary cases for 2027

These independent cases are for the Landscape Agent; they do not replace the existing assignment primary and contrast cases. Each is a hypothetical organization and a 2027 decision scenario drafted on November 16, 2026. No 2027 development or outcome is represented as known. Their proposed monitoring thresholds are decision-design prompts, not observed results.

| Case | Technology | Decision setting |
|---|---|---|
| [01](01_agentic_ai.json) | Tool-using AI agents | Invoice-exception sandbox |
| [02](02_quantum_computing.json) | Error-corrected quantum computing | Portfolio-optimization research |
| [03](03_crispr.json) | CRISPR-edited cell therapy | Specialist referral pathway |
| [04](04_geothermal.json) | Enhanced geothermal systems | Conditional power contract |
| [05](05_sodium_ion.json) | Sodium-ion battery storage | Warehouse storage pilot |
| [06](06_humanoid_robots.json) | Generalist humanoid robotics | Segregated tote-handling pilot |
| [07](07_brain_computer_interface.json) | Speech brain-computer interface | Early-feasibility research partnership |
| [08](08_post_quantum.json) | Post-quantum cryptography | Utility-meter laboratory migration |
| [09](09_direct_air_capture.json) | Direct air capture and storage | Conditional carbon-removal procurement |
| [10](10_confidential_computing.json) | Confidential computing | Synthetic-data analytics pilot |
| [11](11_edge_computing_laptops.json) | Edge AI on laptops | Offline field-service documentation |

The set targets emerging applications and implementation frontiers; it does not assert that each underlying technology is universally bleeding edge. In particular, published post-quantum standards and existing gene-therapy approvals should not be mistaken for proof that the proposed deployment is mature or ready. These are inputs, not completed agent runs or contrast tests.

Every case contains one dated, scope-limited source seed. It is **not** the textbook's complete five-to-six-source tracking set and cannot establish that an application has crossed the chasm. Before producing an actual assessment, assemble and document independent tracking sources, publication cadence and latest edition, and where possible multiple years of comparable editions. Verify all time-sensitive claims at the decision date. The sensitive clinical and infrastructure scenarios are planning exercises and require qualified, site-specific review and all applicable approvals.

Build a packet from the repository root, for example:

```sh
python3 tools/build_prompt.py --agent agents/landscape_agent --case agents/landscape_agent/cases/primary_2027/01_agentic_ai.json
```

## Textbook connection

Andres Fortino's *Mastering the Craft of Emerging Technology Adoption* (2026 draft) frames adoption as a contextual decision rather than a prediction contest. The cases apply its three levels of analysis, the distinction between diffusion and the individual organization's decision (chapters 6 and 8), implementation readiness and ownership (chapter 9), and dated evidence, alternatives, hype checks and monitoring triggers (chapter 10). They invite bounded experiments and human judgment; no case claims a validated adoption decision, a proven business case, or a confirmed Promethean classification. The textbook is an unpublished draft and is not included in this repository.
